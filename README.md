# MarketBar

macOS 菜单栏行情与持仓监控：黄金积存金实时价格 + 自选股票/ETF 的量能与当日盈亏，另配一个会跟着行情变表情、可以聊天的桌面浮动人物。

积存金数据来源于京东金融。

## 功能

### 菜单栏实时金价

- 菜单栏只显示当前黄金价格，例如 `926.41`，不显示数据源名称与涨跌幅
- 支持切换数据源：`浙商积存金` / `民生积存金`
- 刷新频率可选 `1 / 2 / 5 / 10 秒`，接口取值失败时显示 `0.00`

### 悬浮行情面板

鼠标悬停在菜单栏价格上即弹出，移开自动消失，共四段：

- **价格头**：数据源、金价、涨跌幅
- **行情数据**：伦敦金、黄金T+D、伦敦金换算 (¥/g)、溢价 (¥/g)、离岸人民币、美元指数
- **自选行情**：支持沪深北、港股和美股；自选标的显示名称、量能、股数、成本、现价、当日盈亏和浮动盈亏
  - **报价时效**：逐只按市场当地时间判断，名称前标出「旧 / 休市 / 延迟 / 未核时 / 无价」；把鼠标移到股票名称或现价上，面板底部的「报价时间」会直接显示该市场当地的时间与状态，系统悬停提示还会解释原因。正常交易时段内超过 3 分钟未更新会标为「延迟」，全局「更新时间」仅表示应用刷新时间
  - 鼠标从菜单栏金价移入悬浮面板时，穿过两者间的窄缝不会立即收起面板；停在股票名称或现价上稍等即可看到报价时间提示
  - **量能**：按各市场当地正常交易时段进度折算预估全天量，再除以昨日全天量。`≥1.2` 标「放量」（红）、`≤0.8` 标「缩量」（绿）；开盘 15 分钟内及日线数据过旧时显示 `--`
  - **股数 / 当日盈亏**：持仓股数来自配置文件；当日盈亏 = 今日涨跌额 × 股数。A 股金额是人民币；港股和美股分别显示 `HKD` / `USD`，**不把不同币种相加**。A 股只在交易日 09:00–15:30 显示；外盘只在当地正常时段且行情日期为当地当天时显示，盘前盘后不计
- **信息**：更新时间、刷新频率、价格提醒

行情一次请求批量拉取（腾讯 `qt.gtimg.cn`），跟随刷新频率一起更新。美股只显示普通报价（不含盘前/盘后价）；免费接口可能延迟，行情仅供参考，不应用于交易决策。

### 桌面浮动人物

- 桌面右下角默认显示 `240×240` 的可拖动透明人物，尺寸五档：`160 / 200 / 240 / 280 / 320`
- 金价下跌显示悲伤姿态，上涨、持平或暂无数据时显示开心姿态
- 举牌第一行是金价，第二行是**持仓当日盈亏合计**（如 `-8,055`）；两行都用固定中性墨色、不随涨跌变色，数字按长度自动缩放，盈亏那行字号更大
- 非交易日（周末、法定节假日）不显示数字，改显示问候语（如「周末愉快 · 出去走走」「国庆节 · 节日快乐」）
- 人物会持续进行柔和的呼吸、漂浮与摇摆，每 10–15 秒自动切换动作；点击会从当前情绪的 8 个动作中随机播放
- 单击播放随机动作，双击会根据行情表演庆祝或生气；3 秒内点第 3 次会不耐烦，第 4 次躲到价格牌后并进入 8 秒冷却
- 相邻两次有效报价变化达到 `1.00 元` 时立即切换到庆祝/沮丧动作（冷却 45 秒）
- 快速拖动松手后有惯性、落地与回弹；拖到屏幕左右边缘会吸附成「价格牌 + 偷看脑袋」的紧凑模式，向内拖 48pt 恢复
- 菜单 **「浮动窗口 → 拖到边缘自动隐藏」**（默认关）：打开后拖到屏幕左右边缘会**直接收起人物**，想再见到它走「浮动窗口 → 显示人物」
- 5 分钟无人操作会进入困倦姿态并显示 `Zzz…`；屏幕休眠、会话锁定或低电量时暂停动画
- 人物会在点击、快速涨跌、入睡唤醒时显示中文气泡，并偶尔说一句与心情匹配的话
- 有倒计时提醒在跑时，**头顶会挂一块显示剩余时间的小牌子**（气泡会自动往上让位，两者不打架）

### AI 聊天（右键人物）

- **右键**（触控板两指点按）人物 → 弹出聊天窗；左键的单/双/连击动作完全不受影响
- 调用**你自己的 `claude` CLI**（带你的工具、MCP、记忆与默认模型），**复用同一个会话**：关掉窗口、重启 app 后接着聊；终端里 `claude --resume <会话 id>` 也能看到同一段对话
- 换成 `stream-json` 输出，**思考过程与正文都边生成边显示**；标题栏显示本次 token 数（不显示金额），等待时可点「停止」，超时 300 秒
- 打开窗口会载入该会话的历史（直接读 CLI 的会话文件，往上滚可以看到之前聊过的内容）
- 标题栏「会话…」可以查看当前复用的会话 id，也可以粘贴别的 id 接管
- 找不到 `claude` 时窗口里会出现「选择 claude 路径…」按钮手动指定
- ⚠️ 与「在终端里跑 claude」不完全等价：`-p` 是非交互模式，**需要授权确认的工具会被直接拒绝**，不会弹窗询问
- 菜单 **「问 AI：当前行情…」** 会在聊天输入框插入可编辑的行情快照草稿（最多 20 只自选，标出过期报价）；**不会自动发送**，也不包括你的持仓股数、成本或盈亏。确认内容后按 Enter 才会提交给 claude

### 提醒

菜单「提醒」里可以添加多条提醒，每条 = **触发方式 + 文案 + 提醒方式**。

**触发方式两种，二选一：**

- **定时**：某个时刻（精确到秒）+ 重复规则 —— **每天 / 每周某天 / 每月某号 / 每 N 天**（每 N 天以创建那天为起算点，编辑不会重置）
  - 可选**「智能跳过节假日」**：勾上后法定节假日与普通周末都不提醒，但**调休补班的周六/周日照常提醒**；不勾选（默认）则一律照常提醒
- **倒计时**：从现在起一段时长，**剩余时间实时显示在人物头顶**（一颗小牌子，每秒刷新）；菜单里也会带上剩余时间
  - 可选**「到点后自动重新计时」**，就成了番茄钟；编辑时勾「从现在重新计时」可以把手上的这一轮重新起算

**提醒方式两种，可以只开一个，也可以两个都开：**

| 勾选 | 到点时的行为 |
|---|---|
| 宠物提示 | 人物冒气泡说出内容 + 响一声 |
| 弹窗 | 直接弹置顶模态框（「知道了」/「10 分钟后再提醒」，顺延最多 6 次） |
| 两个都勾 | **先气泡，等一段时间没人理再弹窗**；在气泡显示期间**单击气泡或宠物**即可确认本次提醒、不再弹窗（其它提醒与顺延不受影响） |

- 人物被隐藏时，含「宠物提示」的提醒（包括两个都勾）保持静默；只勾「弹窗」的提醒仍会弹出
- 弹窗里的「10 分钟后再提醒」对定时、倒计时和价格提醒都有效；删除对应提醒后不会再顺延
- 上面那个等待时间在菜单 **「提醒 → 提示后多久弹窗」** 里调，**默认 30 秒**，可选 10 / 15 / 30 / 45 秒、1 / 1.5 / 2 分钟；选完立即生效并记住

- 两个都不勾是选不上的（取消最后一个会自动弹回去），保证不会有「静默不提醒」的提醒
- 菜单里有「测试：立即提醒」可以跳过等待看效果
- 节假日与调休数据每天自动拉取一次（timor.tech），缓存在本地；拉不到时按「没有节假日」处理，不会漏提醒

### 微信未读徽标

- 主微信与微信小号的未读数会显示在**人物头部两侧**（左＝主微信、右＝微信小号）
- 有未读显示红底数字（超过 99 显示 `99+`），没有未读显示一颗灰圈
- **点徽标即可打开对应微信的聊天框**（窗口关了也会重新开出来；没运行则先启动）
- 依赖「辅助功能」权限；**每次重新安装 app 后需要重新授权**（签名变化会让旧授权失效）
- 点击未读徽标的「!」会直接打开系统设置中的授权列表，不再同时弹出系统授权提示
- 授权状态每 3 秒检查一次：应用曾检测到无权限，之后发现已授权时会**自动启动新进程并退出旧进程**；聊天窗、配置窗口或模态框打开时先等它们关闭，以免丢失未发送内容。macOS 有时不会在旧进程里更新授权状态，此时需手动退出并重新打开

### 价格提醒

- 支持**高价提醒**（金价 ≥ 设定值）与**低价提醒**（金价 ≤ 设定值）
- 触发时按该条提醒选择的「宠物提示 / 弹窗」呈现；每次穿越阈值只通知一次，勾选重复提醒时价格回落后自动复位

## 配置自选与持仓

菜单 **「自选配置 → 编辑自选与持仓…」** 打开配置窗口，一张表管两件事：

- **搜索添加**（加行的唯一入口）：输入**代码 / 中文名 / 拼音首字母**（`600519`、`00700`、`AAPL`、`腾讯控股` 都行）即时出候选，↑↓ 选择、回车或点一下加入清单；已经加过的会标成灰字「已在清单」
  - 多打一个字导致整个词匹配不上时，会自动退回用最长能匹配的前缀再搜一次，并在提示行说明是按哪个词匹配的 —— 边打字边搜，候选不会因为你打得越准反而消失
- **删除 / 上移 / 下移** 调整清单与顺序（面板里就是按这个顺序排的）
- **名称 / 代码 / 股数** 三列直接编辑；股数留空表示只关注不持仓（如指数）
- **自动补全**：只填代码，名称会自己补上；只填名称，代码也会补上（重名的标的多，只有候选唯一或名字完全对得上时才敢填，否则留空让你自己搜）
- 代码只填 6 位数字会自动补沪深北前缀；5 位数字会补 `hk`；美股代码会补 `us`（例如 `AAPL` → `usAAPL`，`BRK.B` → `usBRK.B`）
- 外盘成本按交易市场本币填写；面板上的港股和美股盈亏单独标 `HKD` / `USD`，人物举牌的人民币合计只包括 A 股持仓
- 保存前会校验：代码为空、格式不对、重复的代码都会被拦下并指出是第几行
- 所有改动点「保存」才落盘，「取消」或直接关窗都不会动配置

配置本身是 JSON，存在：

```
~/Library/Application Support/MarketBar/watchlist.json
```

想直接改文件也行，菜单里有 **「打开配置文件…」**，改完点 **「重新载入配置」** 生效。

格式：

```json
{
  "watchlist": [
    { "code": "sh000001", "name": "上证指数" },
    { "code": "sh512170", "name": "医疗ETF华宝", "shares": 1100000 },
    { "code": "hk00700", "name": "腾讯控股", "shares": 100, "cost": 420 },
    { "code": "usAAPL", "name": "苹果", "shares": 10, "cost": 300 }
  ]
}
```

- `code` 是腾讯行情代码：`sh` / `sz` / `bj` + 6 位数字，`hk` + 5 位数字，或 `us` + 美股代码；`name` 是显示名
- `shares` 留空表示只关注不持仓，`cost` 是该股交易币种的每股持仓成本；旧版独立 `holdings` / `costs` 格式仍可读取
- 文件不存在时会用内置默认值生成一份；文件损坏会回退默认值并保留一份 `.broken.json`
- ⚠️ 持仓代码必须是自选清单的子集：面板的行由自选清单生成，多出来的持仓既不会有行、也拿不到行情，会静默不计入合计。配置窗口会把这类代码补成行显示出来，免得看不见就被悄悄丢掉

## 运行方式

**Xcode**：打开 `Package.swift` → 选择 `MarketBar` 可执行目标 → 运行

**命令行**：

```bash
swift build
.build/debug/MarketBar
```

**测试**（本机只装了 Command Line Tools 时需要指定 Xcode 工具链）：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

## 打包发布

```bash
bash scripts/build-dmg.sh
```

自动完成 release 编译 → 生成 `.app` → 制作 DMG，产出在 `dist/`：

- `MarketBar.app` — 应用包
- `MarketBar-1.0.10.dmg` — 安装包（含 Applications 快捷方式，可拖拽安装）

⚠️ 打包脚本会做本机 ad-hoc 签名，但未进行 Apple Developer ID 公证；从互联网下载的应用仍可能被 Gatekeeper 拦下。

## 技术实现

| 模块 | 技术方案 |
|------|----------|
| UI | AppKit（NSStatusBar + NSMenu + 自绘窗口） |
| 网络请求 | URLSession + async/await，多请求并发（`async let`） |
| 行情解析 | JSONDecoder（金价/行情）+ 腾讯文本行解析（GBK 用 ISO-8859-1 无损解码） |
| 交易日历 | timor.tech 节假日接口，每天拉一次缓存在 UserDefaults |
| AI 聊天 | 子进程调用 `claude` CLI，`stream-json` 流式解析，复用同一会话 |
| 微信未读 | Accessibility API 读状态项（`AXExtrasMenuBar`） |
| 通知提醒 | 自绘 Toast + 人物气泡 + 置顶模态框 |
| 标的搜索 | 腾讯 smartbox 建议接口，支持代码/中文名/拼音；名字是 `\uXXXX` 转义，自行还原 |
| 数据持久化 | UserDefaults（设置、提醒、节假日缓存）+ JSON 配置文件（自选清单） |
| 并发安全 | Swift 6 Strict Concurrency |
